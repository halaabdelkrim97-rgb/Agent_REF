description: Report skills used, token use, plan status and improvements for this session
---

Write the session report defined in the REF rules (section 9, "Session report"). Keep it under about 15 lines:

1. **Skills used:** each REF skill you actually opened in this session, why, and any reference file read.
2. **Tokens:** only figures the environment shows (the user can run `/cost` and `/context`). If you cannot see them, write "not measured" and a labeled rough estimate (small, medium, large). Never invent numbers.
3. **Plan:** done, in progress, next (max 5).
4. **Improvements:** up to three concrete suggestions. Offer to apply them with the `reflect` skill, with the user's approval.

Do not open any additional skill or file to write the report.
