How this works

Equation: m·x'' + c·x' + k·x = 0. Integration: semi-implicit Euler at a fixed 1/240 s step. Natural frequency ω0 = √(k/m). Damping ratio ζ = c / (2·√(k·m)). ζ<1 oscillates, ζ=1 is critical, ζ>1 is overdamped. Check: with c=0 the period is 2π√(m/k). This is an illustrative model, not a design tool.
