# UI/UX Pro Max

Use the user's brief, references and existing tokens as the visual authority. This skill supplies implementation guidance and searchable reference material, not a house style. Preserve requested typography, palette, density, emoji use or visual effects unless a concrete accessibility/usability issue requires discussion.

## Focused procedure
1. Identify the task: layout, interaction, accessibility, typography, palette or requested style exploration. Do not generate a whole design system for a small change.
2. Reuse defined choices. For new artistic direction or weak visual fidelity, use art-direction. Ask only about a missing decision that materially affects the result.
3. Implement semantic structure, visible keyboard focus, labeled inputs, clear feedback, readable content, target-appropriate touch interaction and responsive layout. Account for loading/error/empty states when relevant.
4. Verify the changed viewport/state against the brief. Distinguish functional/accessibility defects from subjective preferences. Measure contrast and performance when claiming they pass.

## Optional searches
Use [the detailed catalog and search instructions](references/catalog-and-search.md) only when specific palette, type, UX or style references are needed. Search the relevant domain rather than automatically searching every domain or stack. Check that scripts/runtime exist; reuse available tooling and ask before installing anything. Never present a recommendation from a catalog as the user's preference.

The preserved catalog includes opinionated defaults. Its style prohibitions, numeric starting points and mandatory search workflows are reference suggestions, subordinate to the user's brief and current accessibility requirements. Verify version-sensitive standards rather than quoting an unverified universal threshold.
